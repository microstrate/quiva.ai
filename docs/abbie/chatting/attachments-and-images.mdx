## Sending files

Drop a file anywhere on the chat window and a full-screen dropzone appears; drop it and it attaches to your next message. You can also attach through the message box directly.

Attached files and images show a preview in the transcript. If you send two files with the same name in the same conversation, Abbie tells them apart by labelling the second with when it was uploaded, so you're never looking at an ambiguous "which one is this" filename.

Abbie routes your request to a model that can actually read what you've sent, whether that's an image, a document, or whatever the case calls for, and will tell you plainly if a particular attachment isn't something she can work with, rather than silently ignoring it.

## Receiving images

If you ask Abbie to generate an image, she may post a short holding message while it's being produced, then the finished image lands in the conversation as a normal message you can scroll back to later. It isn't temporary.

<Note>
Attachments and generated images stay attached to the session they were shared in, alongside the rest of that conversation's history.
</Note>
