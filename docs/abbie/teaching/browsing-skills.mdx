[Importing](/abbie/teaching/creating-and-importing-skills) a skill is a manual step: you supply a folder or a URL yourself. **Browse** is the other way in — a catalogue built from GitHub repositories that publish their own skill manifest, so you can look through what's on offer and install without leaving the Skills tab.

## Where skills come from

Open **Browse** on the Skills tab to see everything available from your account's trusted source repositories. Anthropic's public skills repo is included by default. You can add other source repos your account trusts, or remove ones you don't want listed, from the same screen.

<Note>
Browsing only ever shows skills from repos your account has explicitly trusted. Nothing from a source you haven't added shows up in the catalogue.
</Note>

## What each entry shows

- **Source repo**: which repository the skill was published from.
- **Licence**: as declared by the author.
- **Compatibility note**: any caveat the author has flagged, shown when they've provided one.
- **"Ships scripts"**: a warning shown when the skill bundles executable code alongside its instructions. See [Running a skill's scripts](/abbie/teaching/running-skill-scripts) for what that means and how approval works.

## Installing

Installing from Browse is one click, and it reuses the same import path as a manual import — the skill lands on your account exactly as if you'd imported its bundle yourself, ready to review, edit, or turn on.

## If a source repo is unreachable

If one of your trusted source repos can't be reached, it shows as an inline notice in the catalogue rather than blocking the page. The rest of the catalogue still lists normally.
