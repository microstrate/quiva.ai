The **Integrations** tab in [Abbie's settings](/abbie/configuring/settings-overview) is split into three sections.

## Chat platforms

Where Abbie is reachable outside QuivaWorks. See [Slack](/abbie/connecting/slack).

## Abbie's identity

Whether Abbie has her own dedicated login for a given integration, separate from anyone's personal connection. An account admin can give her one directly from this section. See [Credential identity](/abbie/connecting/credential-identity) for why this matters.

## Integrations catalogue

The full list of integrations available to your account, split into what Abbie is authorised to use and what's merely available.

Abbie's catalogue is intentionally visible to her even before anything is authorised. It's what lets her recognise "I could do that through Xero" and ask, rather than needing to be told an integration exists. Actually using one always requires authorisation first; see [Decisions and authorisations](/abbie/chatting/decisions-and-authorisations).

Each integration shows which login would back it if Abbie used it right now:

| Label | Meaning |
|---|---|
| **No sign-in needed** | Nothing to connect; it's usable as-is. |
| **Abbie's login** | She has her own dedicated login for this. |
| **Your login** | She'd use your personal connection. |
| **Needs connecting** | Nobody has connected this integration yet. |

Authorising an integration for Abbie is an account-wide decision, so toggling it on or off is an admin action.

<Note>
An integration that needs credentials configured elsewhere (rather than a simple sign-in) can't be connected from this page. An admin will need to set it up through wherever that integration's credentials are managed.
</Note>
