When an item on Abbie's backlog is promoted to a real task — either by you choosing **Promote to
task** on the [Backlog page](/abbie/backlog/backlog-page), or by Abbie creating one herself — it
has to be filed into a [Space](/spaces/spaces).

The **Task filing** tab sets which Space that is, when nothing more specific applies.

## What it governs

- **Promoting a backlog item to a task**, where you have not picked a Space yourself.
- **Abbie creating a task directly**, as part of doing something you asked for.

## Setting it

Choose a Space from the list and save. It is an account-wide setting, so changing it is an admin
action — everyone else can see which Space is set but cannot change it.

<Note>
This is a **default**, not a restriction. Promoting an item by hand still lets you choose a
different Space at the time. The default is what applies when nobody chooses.
</Note>

<Tip>
Pick a Space someone actually watches. A default pointing at a Space nobody opens is how tasks
quietly accumulate unseen — which looks, from the outside, exactly like Abbie not creating them
at all.
</Tip>
