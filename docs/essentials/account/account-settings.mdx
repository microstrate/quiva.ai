Account settings cover everything that applies to the whole account rather than to one person.

Open **Account** in the sidebar — depending on your account it sits at the top level or under **More**. The page is visible to the **root** and **admin** roles only.

<Info>
This is one page with a settings list down the left, not a set of tabs. Each section is also addressable directly with `?tab=` — for example `?tab=retention`.
</Info>

The sections are **Details**, **Branding**, **Global Instructions**, **Global Knowledge**, **Escalation Responders**, **Data Retention** and **Specialization**.

<Note>
Personal preferences — your profile, theme, notifications, password and sessions — live somewhere else entirely, under **Settings** in the user menu. [Personal settings →](/essentials/users/user-settings)
</Note>

## Details

The **Account Details** card holds the account's identity and contact information.

| Field | Notes |
|---|---|
| Account Name | Editable by root only. Admins see it read-only. |
| Owner Email | Read-only here. |
| Company/Entity name | |
| Address | |
| Website | |
| Phone Number | |
| Country | The country or region where the business is registered. If you operate as an individual, the location you work from. |

Click **Save** to store changes to the contact fields.

**Close Account** also sits in this card. It is root-only and disappears once a deletion has already been scheduled. [Closing your account →](/essentials/account/closing-account)

### Renaming the account

Only the root user can rename an account. Editing **Account Name** enables a **Rename Account** button, which opens a confirmation modal.

<Warning>
Renaming signs out you and every member of the account. Everyone must use the new account name to sign in again, and an email notification about the change is sent to everyone affected.
</Warning>

To confirm, click **Send code**, enter the code emailed to you, then click **Apply Change**. If the code does not arrive, you can request another once the countdown on the button finishes.

<Note>
Account names are matched case-insensitively — they are lowercased and trimmed when stored, so `AcmeOps` and `acmeops` are the same name.
</Note>

## Escalation Responders

Pick the people who handle escalations when nobody more specific is named.

The section holds a single **Assignees** multi-select. The selected users are notified for any escalation task and are authorised to respond when no responder is set on the assistant or flow that raised it.

<Info>
If no default responders are set, the account root is the default responder.
</Info>

Click **Save** to apply.

## Data Retention

Controls how long your assistants' conversation history is kept before it is permanently deleted.

Set a **Retention period (days)** and click **Save**.

<Note>
This is separate from pipeline execution traces and diagnostics, which are always kept for 7 days no matter what you set here.
</Note>

How high you can set it depends on your plan:

| Plan | Self-serve ceiling |
|---|---|
| Free | 45 days |
| Pro | 90 days |
| Team | 365 days |

A banner at the top of the section shows the current setting in plain language.

Setting the field to `0` means keep conversation history forever. That is not self-serve — it needs a platform-issued override, and an account running under one shows a **Platform override in place** warning. You can always lower the period yourself; raising it back above your plan's ceiling requires contacting us again.

[Compare plans →](/essentials/account/billing-subscriptions)

## Specialization

A dashboard for the account's verticals, where you can view, customise and extend the configurations deployed for your vertical. A **Get Help Setting Up** button opens a setup assistant.

## Data hosting

Where an account's data is hosted is chosen once, on the onboarding screen **"Choose the way your data is hosted"**, which is shown to any account that has no regions set yet. The region on offer is **Europe**, and the node count is a choice between **1** and **3**.

<Warning>
Three nodes means three copies of your data, so it uses three times the storage.
</Warning>

The choice is not gated on your plan. [Creating your account →](/essentials/account/creating-account)
